## 🎯 O projekcie

**Veyra** zastępuje `explorer.exe` jako powłoka systemu. Odpowiada za pulpit, ikony, pasek zadań i uruchamianie aplikacji, a robi to szybciej i z mniejszym zużyciem pamięci.

> [!NOTE]
> Veyra to **powłoka**, a nie menedżer plików. Do przeglądania folderów możesz używać dowolnej aplikacji.

## 🚀 Instalacja

1. Pobierz najnowszą wersję z [Releases](../../releases).
2. Uruchom instalator i postępuj zgodnie z instrukcjami.
3. Wybierz Veyra jako powłokę podczas instalacji.

> [!TIP]
> Chcesz wrócić do Eksploratora? Wystarczy odinstalować Veyra lub wybrać Eksplorator w ustawieniach instalatora.

## ⌨️ Skróty klawiszowe

| Skrót | Akcja |
| --- | --- |
| <kbd>Win</kbd> | Otwórz launcher |
| <kbd>Win</kbd> + <kbd>E</kbd> | Otwórz menedżer plików |
| <kbd>Alt</kbd> + <kbd>Tab</kbd> | Przełącz okno |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>R</kbd> | Przeładuj konfigurację |
